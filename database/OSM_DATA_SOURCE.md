# OpenStreetMap restaurant dataset

`restaurant-data-osm.json` is a 300-record Toronto restaurant and food-service expansion created without Google Places or a Google API key.

## Source

The data was generated by querying the Overpass API for OpenStreetMap nodes and ways tagged as:

- restaurant
- cafe
- fast food
- bar
- pub

The query was restricted to the Toronto administrative area and required a place name.

## Generation

The repeatable builder is:

```bash
cd backend
node scripts/build_restaurants_osm.js
```

The builder writes:

```text
database/restaurant-data-osm.json
```

## Record fields

Each record contains:

- name
- address when address tags are available
- cuisine derived from the OSM `cuisine` tag or amenity type
- neighbourhood when an `addr:suburb` tag is available
- OpenStreetMap type and ID for traceability
- null price level and Google Place ID because those fields are not available from this source

## Data-quality notes

This source is a starting dataset, not a final verified restaurant directory:

- Some records may represent cafés, fast-food locations, bars, or closed businesses rather than full restaurants.
- Some OpenStreetMap records do not have street addresses.
- The current generated file should be reviewed before production use.
- Name/address duplicates should be checked carefully because restaurant chains may have multiple valid branches.
- OSM cuisine labels are community-contributed and may need normalization.
- OSM is not a substitute for Google Places verification of live status, phone number, official address, price level, or photos.

## Import

After a database schema supporting the proposed optional restaurant fields is available:

```bash
cd backend
DATABASE_URL="postgres://restaurant_user:change_me_locally@localhost:5432/restaurant_app" \
  node scripts/import_restaurants.js --import --file ../database/restaurant-data-osm.json
```

The existing importer inserts missing restaurants and updates matching records. It does not require Google Place IDs and falls back to name/address matching.
